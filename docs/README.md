# Engineering documentation

This directory is the home for system-level Littlebot engineering and integration documentation.

The central documentation will cover system requirements, architecture, subsystem responsibilities and interfaces, integration, verification, and engineering decisions. Detailed implementation and API documentation remains in the corresponding subsystem repository.

The existing \`project_managment/\` directory is retained while its initial project-management notes are developed. New documentation should use the correctly spelled \`project_management/\` path when that section is next reorganized.
