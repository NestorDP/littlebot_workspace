Littlebot Engineering Documentation
====================================

Welcome to the Littlebot engineering documentation.

Littlebot is a low-cost differential-drive mobile robot developed
as an integrated robotics platform. This documentation describes
the system architecture, engineering processes, subsystem
responsibilities, and development procedures.
